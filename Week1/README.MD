## My key takeaway this week

Everything this week builds toward one idea: ML is about picking a function that predicts well on *new* data, not just data it's already seen. Statistical decision theory gives the formal way to define "predicts well," and bias-variance explains why getting that right is a balancing act, not a one-shot fix.
